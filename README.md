## 게임 소개

숲, 폐허, 동굴을 거쳐 성채 보스를 쓰러뜨리는 턴제 로그라이크 전투 게임이다. 일반 전투에서 공격, 도구, 도망을 선택하고 승리 보상으로 능력을 강화해 최종 보스에 도전한다.

## 실행 방법

1. Visual Studio 2022에서 `26311013_BaekGyeongBin/26311013_BaekGyeongBin.sln`을 연다.
2. NuGet 패키지를 복원한다.
3. x64 Debug 또는 Release로 빌드 후 실행한다.

## 조작

- 방향키: 메뉴 이동 및 지역·보상 선택
- Enter: 선택 확정
- Esc: 뒤로 / 일시정지 / 타이틀에서 종료
- A / B / Q: 전투 기본 메뉴에서 기본 공격 / 도망 / 회복약

## 구현 범위

- 타이틀, 설정, 전체 화면 전환
- 일반 전투 3회와 성채 보스전
- 기술 3종, 회복 도구 2종, 도망
- 폐허·동굴 선택과 미방문 지역 자동 진행
- 승리 보상 3종, 능력치·도구·점수 유지
- 보스 강공격 패턴, 게임오버·클리어·재시작
- 배경 음악, 선택·결과 시스템 효과음
