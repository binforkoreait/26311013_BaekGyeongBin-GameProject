## 1. 게임 제목

**Dungeon Escape** — 제목은 현재 표지의 이름을 유지한다.

## 2. 게임 개요

여러 바이옴을 여행하면서 적을 만나고, **공격·도구·도망을 선택하는 턴제 전투**로 도전하는 게임이다. 전투에서 얻은 점수와 성장 효과는 이번 도전 동안 유지한다. 패배하면 진행도와 성장, 소지 도구를 초기화하고 처음부터 다시 도전한다.

플레이어가 실시간으로 이동하거나 탄환을 조준하는 액션 방식은 사용하지 않는다. 포켓몬 전투처럼 화면에 플레이어와 적을 배치하고 메뉴에서 행동을 선택한다. 몬스터 수집과 팀 편성은 이번 제작 범위에 포함하지 않는다.

## 3. 게임 목적과 제작 범위

숲·폐허·동굴 바이옴을 거쳐 성채의 최종 보스를 처치한다. 일반 조우 6회와 보스전 1회로 한 번의 도전을 구성한다.

- 플레이어 캐릭터 1종
- 일반 적 3종, 최종 보스 1종
- 일반 바이옴 3종과 성채 1종
- 공격 기술 3종, 도구 2종, 승리 보상 3종
- 바이옴 선택, 턴제 전투, 성장, 점수, 게임오버와 재시작
- 오픈 월드, 실시간 이동·충돌·탄환, 몬스터 수집, 팀 교체, 속성 상성, 상태 이상, 상점, 영구 성장, 중간 저장은 제외

세부 수치는 초기 밸런스안이며 시험 플레이 후 조정한다.

## 4. 바이옴과 진행 방식

| 바이옴 | 분위기 | 주요 적 |
| --- | --- | --- |
| 숲 | 나무와 풀로 둘러싸인 지역 | 숲의 야수 |
| 폐허 | 무너진 건축물이 있는 지역 | 폐허의 수호자 |
| 동굴 | 어두운 바위 지역 | 동굴의 박쥐 |
| 성채 | 최종 결전 장소 | 성채 보스 |

- 첫 지역은 숲으로 고정한다.
- 각 일반 바이옴에서 적을 한 마리씩 만나 총 2회의 조우를 진행한다.
- 두 조우를 마치면 지도에서 다음 바이옴 후보 2개 중 하나를 선택한다.
- 후보는 현재 지역을 제외한 일반 바이옴 두 곳이며, 이전에 방문한 지역도 다시 선택할 수 있다.
- 일반 바이옴을 3번 방문하고 총 6회의 조우를 마치면 성채 보스전에 진입한다.
- 일반 조우는 승리하거나 도망에 성공하면 완료 처리한다. 도망 시 보상과 점수는 없다.
- 바이옴 이동 시 HP와 도구, 강화 효과를 유지한다. 자동 회복은 없다.
- 지역 이동은 지도 선택과 화면 전환으로 표현한다.

## 5. 게임 플레이 방식

1. START를 선택하면 초기 능력치와 도구를 지급한다.
2. 숲 바이옴의 첫 적과 전투한다.
3. 공격·도구·도망 중 행동을 선택한다.
4. 플레이어 행동을 처리한 뒤, 적이 살아 있으면 적이 행동한다.
5. 승리하면 보상 3개 중 하나를 선택하고 다음 조우로 진행한다.
6. 바이옴 선택을 반복하여 성채의 최종 보스에 도전한다.
7. 보스를 처치하면 게임 클리어, 플레이어 HP가 0이면 게임오버가 된다.

## 6. 조작 방법

| 화면 | 키 | 기능 |
| --- | --- | --- |
| 타이틀·설정·전투 메뉴·결과 | ↑ / ↓ | 항목 선택 |
| 모든 선택 화면 | Enter | 선택 확정 |
| 설정 | ← / → | 볼륨 또는 화면 모드 변경 |
| 바이옴·보상 선택 | ← / → | 후보 선택 |
| 공격·도구 하위 메뉴 | ESC | 전투 메뉴로 돌아가기, 턴 소비 없음 |
| 설정 | ESC | 타이틀로 돌아가기 |
| 전투 기본 메뉴 | ESC | RESUME / TITLE 일시정지 메뉴 |
| 일시정지 | ESC | 전투 복귀 |
| 타이틀 | ESC | 프로그램 종료 |

행동 연출 중에는 추가 행동 입력을 받지 않는다. 바이옴·보상 선택은 Enter로 확정하며 ESC로 보상을 건너뛰지 않는다.

## 7. 턴제 전투 규칙

### 플레이어와 턴 순서

- 시작 최대 HP는 100, 현재 HP는 100, 공격력은 20이다.
- 전투는 플레이어 1명과 적 1명의 대결이다.
- 매 턴 플레이어가 먼저 행동하고, 적이 생존하면 적이 1회 행동한다.
- 플레이어 공격으로 적 HP가 0이 되면 즉시 승리하고 적의 행동은 생략한다.
- 적의 행동으로 플레이어 HP가 0이 되면 즉시 게임오버가 된다.
- 메뉴 탐색과 취소는 턴을 소비하지 않는다. 행동 확정 후 결과 문구를 표시하고 다음 단계로 진행한다.
- 피해를 입은 HP는 0 미만으로, 회복한 HP는 최대 HP를 초과하지 않게 한다.

### 공격

공격을 선택하면 기술 목록을 표시한다. 모든 기술은 사용 횟수 제한 없이 사용한다.

| 기술 | 효과 | 성공 확률 |
| --- | --- | --- |
| 기본 공격 | 공격력만큼 피해 | 100% |
| 강한 공격 | 공격력의 1.5배 피해, 소수점 버림 | 75% |
| 흡수 공격 | 공격력의 0.5배 피해, 실제 준 피해의 절반만큼 회복, 소수점 버림 | 100% |

공격이 빗나가도 턴을 소비한다. 방어력과 속도 수치는 이번 범위에서 사용하지 않는다.

### 도구

도구를 선택하면 이름·효과·수량을 표시한다.

| 도구 | 효과 | 시작 수량 |
| --- | --- | ---: |
| 회복약 | HP 30 회복 | 3 |
| 고급 회복약 | HP 60 회복 | 1 |

- 도구 사용 시 수량을 1개 차감하고 턴을 소비한다. 이어서 적이 행동한다.
- 수량이 0이거나 HP가 가득 차 있으면 사용을 막고 안내한다. 이 경우 턴과 도구를 소비하지 않는다.
- 도구는 이번 도전 동안 유지하지만 패배 또는 새 도전 시 시작 수량으로 초기화한다.

### 도망

- 일반 적과의 전투에서만 선택할 수 있으며 성공 확률은 60%이다.
- 성공하면 적의 공격 없이 현재 조우를 마치고 다음 진행 단계로 이동한다.
- 도망 성공 시 점수·성장 보상·도구 보상을 받지 않는다.
- 실패하면 턴을 소비하고 적이 행동한다.
- 보스전에서는 도망 항목을 비활성화한다. 선택 시 안내만 표시하고 턴을 소비하지 않는다.

## 8. 적과 보스의 행동

| 적 | 기본 HP | 기본 공격력 | 행동 |
| --- | ---: | ---: | --- |
| 숲의 야수 | 50 | 10 | 기본 공격 |
| 폐허의 수호자 | 70 | 12 | 기본 공격 |
| 동굴의 박쥐 | 40 | 14 | 기본 공격 |
| 성채 보스 | 200 | 18 | 기본 공격 2회 후 강한 공격 1회 반복 |

- 일반 적의 HP와 공격력은 바이옴 방문 번호가 증가할 때 기본값에 각각 +10과 +2를 더한다. 3번째 방문은 +20과 +4이다.
- 적의 기본 공격은 반드시 명중한다.
- 보스의 강한 공격은 27 피해를 주며 반드시 명중한다.
- 보스의 강한 공격 직전 플레이어 선택 단계에 예고 문구를 표시한다.
- 적 HP가 0이면 처치 처리하고 화면에서 퇴장한다.
- 공격 결과를 문구와 간단한 피격 효과로 표현한다. 실시간 추적과 충돌 처리는 사용하지 않는다.

## 9. 승리 보상과 로그라이크 초기화

일반 적에게 승리하면 다음 3개 보상을 표시하고 하나를 선택한다. 카드 표시 순서는 무작위이며 효과는 명확하게 표시한다.

| 보상 | 효과 |
| --- | --- |
| 공격 강화 | 공격력 +5 |
| 체력 강화 | 최대 HP +20, 현재 HP도 +20 |
| 도구 보급 | 회복약 +2 |

- 강화는 중첩 가능하며 일반 승리 수에 따라 최대 6회 보상을 받는다.
- 도망친 조우에서는 보상 선택 화면을 표시하지 않는다.
- 현재 능력치·도구·점수는 다음 바이옴으로 이어진다.
- **패배하면 바이옴 진행도, 적 진행도, 점수, 능력치 강화, 도구를 초기화한다.**
- 게임오버 화면에 이번 도전 결과를 먼저 표시하고, RETRY 시 초기값으로 새 도전을 시작한다.
- 도전 도중 TITLE로 돌아가도 진행을 저장하지 않는다.
- 영구 강화와 이어하기는 없다. 사운드·화면 설정은 도전 초기화와 별도로 이번 실행 동안 유지한다.

## 10. 점수 및 종료 조건

| 행동 | 점수 |
| --- | ---: |
| 일반 적 승리 | +100 |
| 최종 보스 처치 | +1,000 |
| 도망 성공 | 0 |

- 점수는 이번 도전에서만 누적한다.
- 보스에게 일반 적 점수를 중복 지급하지 않는다.
- 최종 보스 처치 시 GAME CLEAR와 최종 점수를 표시한다.
- 플레이어 HP가 0이면 GAME OVER와 현재 점수·도달 바이옴을 표시한다.
- 결과 화면에서 RETRY 또는 TITLE을 선택한다.
- EXIT 또는 창 닫기로 게임을 종료한다.

## 11. 시작 조건

타이틀에서 START를 선택하면 아래 상태로 새 도전을 시작한다.

```text
현재 HP / 최대 HP = 100 / 100
공격력 = 20
회복약 = 3개
고급 회복약 = 1개
점수 = 0
바이옴 방문 번호 = 1 / 3
일반 조우 번호 = 1 / 6
현재 바이옴 = 숲
획득 강화 = 없음
```

## 12. 화면 구성

### 타이틀

표지 이미지, START / SETTING / EXIT, 선택 강조 표시.

### 설정

SOUND: 0~100%를 10%씩 조절. DISPLAY: 1280×960 창 모드 또는 전체 화면. BACK: 타이틀 복귀.

### 바이옴 선택

현재 위치와 진행도, 다음 지역 후보 2개, 바이옴 이름·배경 미리보기, HP와 점수.

### 전투

바이옴 배경 위에 플레이어와 적을 마주 보게 배치한다. 양측 이름과 현재/최대 HP, 점수와 조우 번호를 표시한다. 하단에는 **공격 / 도구 / 도망** 메뉴와 전투 결과 문구를 표시한다.

공격 하위 메뉴에는 기술명과 효과, 도구 하위 메뉴에는 이름과 회복량·남은 개수를 표시한다. 전투 메뉴는 방향키로 선택하고 Enter로 확정한다.

### 보상 선택

공격 강화 / 체력 강화 / 도구 보급의 효과를 카드로 표시한다. 하나를 선택하면 다음 조우 또는 지역 지도로 이동한다.

### 결과

GAME OVER 또는 GAME CLEAR, 이번 도전의 점수와 도달 지역, RETRY / TITLE.

## 13. 게임 진행 흐름

```text
타이틀 → START → 새 도전 초기화
  ↓
숲 조우 1 → 승리 시 보상 / 도망 시 보상 없음
  ↓
숲 조우 2 → 승리 시 보상 / 도망 시 보상 없음
  ↓
바이옴 선택 → 조우 3, 4 → 각 승리 시 보상
  ↓
바이옴 선택 → 조우 5, 6 → 각 승리 시 보상
  ↓
성채 보스 → 승리 → GAME CLEAR

각 전투: 행동 선택 → 플레이어 행동 → 승리 판정
         → 적 행동 → 패배 판정 → 행동 선택 반복

HP 0 → GAME OVER → RETRY → 모든 도전 상태 초기화
```

## 14. 주요 게임 객체

| 객체 | 역할 |
| --- | --- |
| Game / CApplication | 실행, 장면 전환, 도전 초기화 |
| Player | HP, 공격력, 강화와 도구 소지 수량 |
| Enemy / Boss | 적 능력치, 행동 선택, 보스 패턴 |
| Battle | 턴 순서, 행동 처리, 승리·패배·도망 판정 |
| Skill | 기술 피해량, 명중과 회복 효과 |
| Item | 도구 효과, 사용 가능 여부와 소비 |
| Biome | 배경, 조우 적, 다음 지역 후보 |
| RunProgress | 방문 번호, 조우 번호, 누적 점수 |
| Reward | 승리 보상 표시 및 적용 |
| UI / Scene | 화면, 메뉴 선택, HP와 결과 문구 |
| GameAudio | 볼륨 및 사운드 관리 |

3주차에 실제 클래스별 멤버·함수·관계를 구체화한다. Bullet, 이동용 Map, 실시간 충돌 객체는 이 턴제 기획의 필수 객체가 아니다.

## 17. 현재 개발 상태

- 타이틀 이미지, START / SETTING / EXIT 및 방향키 선택 코드 작성

- 1280×960 프로젝트 빌드 성공 확인
- START는 아직 준비 중 화면
- 바이옴 선택과 턴제 전투, 기술·도구·도망·성장 초기화는 앞으로 구현할 기능

### 3주차
